# 数据中心完整指南

数据中心像 CF Compass 的“本地保险箱”：一边从 Codeforces 拉取公开记录，一边负责训练数据的备份、迁移和恢复。它不需要额外账户，也不会索取 Codeforces 密码。

![CF Compass 数据中心](./screenshots/data-center.png)

> 图片中的训练账号与统计数据经软件使用者授权用于演示；电脑用户名、绝对路径和私人备份文件名均未公开。

## 第一次使用的推荐设置

1. 在顶部输入自己的 Codeforces Handle，先完成一次 **同步数据**。
2. 打开数据中心，确认提交记录、题库缓存和 Rating 记录已经出现。
3. 保持 **自动同步** 开启，推荐间隔为 30 或 60 分钟。
4. 保持 **自动备份** 开启，推荐保留 14 或 30 份。
5. 在重要比赛或大量整理笔记后，点击 **导出全部数据**，把 JSON 文件复制到自己的安全位置。

## 顶部四张状态卡

| 卡片 | 含义 |
| --- | --- |
| 本地提交 | 当前缓存中保存的 Codeforces 提交数量和最新提交 ID。 |
| 上次新增 | 最近一次同步新发现的提交数量，并标明是完整还是增量同步。 |
| 自动备份 | 当前是否开启，以及最多保留多少份备份。 |
| 备份文件 | 本机备份目录中的 JSON 数量和最近创建时间。 |

## 增量同步如何工作

第一次同步或更换 Handle 时，应用会建立完整本地缓存。后续同步会从最新提交开始读取，遇到已经保存的提交 ID 后停止，再把新记录与旧记录合并去重。

同步还会处理：

- Codeforces 用户公开信息；
- 提交历史和题目通过状态；
- Rating 历史；
- Rating 排名位置；
- 赛事复盘索引；
- 比赛中心缓存。

题目全集体积较大，因此在 **题库缓存** 尚未到期时直接复用。缓存到期后，下一次同步才重新获取完整题库。

### 自动同步

自动同步只在应用在线、窗口可见且当前没有其他同步任务时运行。启动后会检查是否已经超过设定间隔；失败后不会连续轰炸 API，而是等待下一个完整间隔再试。

建议：

- 日常使用：30 或 60 分钟；
- 偶尔打开：3 小时；
- 比赛刚结束：可手动点击 **立即增量同步**。

## JSON 数据保险箱

### 导出全部数据

导出的 `CF-Compass-backup-日期.json` 包含：

- Codeforces 题库与提交缓存；
- 收藏题目；
- 笔记、复习状态、训练计划与设置；
- 已计算的赛事复盘记录。

本地人物图片、视频、源码模板文件和 Codeforces 密码不在这个 JSON 中。

### 导入备份

导入会替换当前题库缓存、收藏、学习记录和赛事复盘数据。应用会先展示确认框，并在真正替换前强制创建一份 **导入前备份**，因此误导入仍有回退路线。

只接受 CF Compass 自己生成的备份格式；超过 200 MB 的文件会被拒绝，避免误选异常文件。

### 打开备份文件夹

点击后会打开 CF Compass 的本机备份目录。不要在教程截图、Issue 或公开聊天中复制完整路径，因为路径通常包含 Windows 用户名。

## 自动备份规则

- 同一天的普通自动备份只创建一次，避免每次操作都生成重复文件。
- 同步数据和学习记录变更都可以触发备份检查。
- 导入前备份属于强制安全快照，不受“当天已备份”限制。
- 超过 **保留备份** 数量后，应用自动删除更早的备份文件。

自动备份保存在本机，并不等于异地备份。如果硬盘损坏，只放在同一台电脑里的副本也会一起丢失，所以重要阶段仍应手动导出到其他磁盘或自己的可信云盘。

## 训练相关设置

| 设置 | 影响 |
| --- | --- |
| 每日复习 | 今日训练中最多出现多少道到期复习题。 |
| 复习难度范围 | 自动跳过明显低于当前水平的题；“智能调整”适合多数用户。 |
| 三档推荐 | 控制巩固、同段、挑战三组题目的数量。 |
| 题库缓存 | 指定完整题库可以复用多久；提交记录仍可增量更新。 |

## 最近数据活动

右侧时间线会记录同步、自动备份、手动导出和导入等关键操作，便于回答“数据什么时候变了、刚才到底做了什么”。界面最多展示最近一部分记录，活动日志本身保存在本机。

## 换电脑

旧电脑：

1. 打开数据中心，点击 **导出全部数据**。
2. 把生成的 JSON 文件安全复制到新电脑。

新电脑：

1. 启动相同或更高版本的 CF Compass。
2. 打开数据中心，点击 **导入备份**。
3. 确认 Handle、收藏、笔记、复习和赛事复盘均已恢复。
4. 本地人物背景和算法模板源码不在训练 JSON 中，需要单独复制或重新选择目录。

## 误操作恢复

1. 暂停继续编辑，避免产生更多覆盖。
2. 点击 **打开备份文件夹**，按修改时间找到操作前的 JSON。
3. 回到数据中心选择 **导入备份**。
4. 确认恢复完成后，再手动导出一份新的稳定快照。

## 隐私说明

- 同步使用的是 Codeforces 公开 API，不接收账号密码。
- 训练记录、笔记、设置、活动日志和备份默认留在本机。
- JSON 可能包含 Handle、做题记录和私人笔记，分享前请先检查内容。
- 报告问题时优先描述按钮和错误提示，不要上传未经检查的完整备份文件。
