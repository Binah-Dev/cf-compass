# CF Compass v4.0.2

这是一次头像可靠性与发布链路维护版本，功能范围保持克制，不包含正在开发中的 v4.1 实验功能。

## 修复内容

- 修复 Codeforces API 图片源暂时返回错误时，个人进度页头像长期空白的问题。
- 头像现在优先使用 Codeforces 主站代理地址；如果加载失败，会依次尝试 API 返回的原始图片地址，最后显示用户姓名首字母占位。
- 无效地址会被过滤，HTTP 地址会安全升级为 HTTPS，避免混合内容导致的加载失败。

## 下载建议

Windows 日常使用推荐下载 `CF-Compass-4.0.2-Windows-x64-Setup.exe`。便携版适合临时体验，但每次启动都需要释放程序文件，通常比安装版慢。

Linux 提供 AppImage 与 deb；macOS 请按 Intel 或 Apple 芯片选择对应 dmg。本次所有平台产物均从同一 v4.0.2 提交在对应原生环境重新构建。

> 公共构建暂无商业代码签名证书。请只从本仓库 Release 下载，并使用随附的 `.sha256` 或 `SHA256SUMS.txt` 核对文件。

## 发布验证

- 完成前端生产构建、头像来源单元回归、头像真实界面回归及既有核心测试。
- Windows、Linux x64、macOS Intel、macOS Apple 芯片执行原生构建。
- Windows 安装版执行隔离安装、连续两次启动、卸载与用户数据保留验证。
- 安装版和便携版从正式 Release 重新下载，核对 SHA-256 后执行真实冷启动验证。
