# CF Compass v4.4.0

## 模板待做与复习进度

- 模板卡片支持加入待做题单，在主窗口和独立题单中都可直接用 VS Code 打开原文件。
- 卡片显示待复习、已复习和累计完成次数；算法分类与模板库概览显示复习进度。
- 每轮待做完成计一次。取消完成会撤回本轮，点击“再复习”后完成可继续累加；移出待做队列保留累计次数。
- 升级前仍标为已完成的模板按一次迁移；过去没有记录的复习轮次无法补算。
- 切换模板目录后，队列中来自以前所选目录的文件仍可打开。中文、空格和井号文件名得到正确保留；未选择过的目录仍受路径检查约束。

## 待做顺序

新加入的题目追加到末尾，早加入的排在前面。旧队列按加入时间整理一次，之后手动拖动的顺序会保留；再次加入已完成题目会作为新一轮排到末尾。

## 自建题单

在题库顶部点击“新建题单”并填写名称，通过题名右侧的收录按钮选入题目。同一道题可收录到多份题单；支持切换查看、按原有条件筛选、重命名、移出题目和删除题单。删除题单保留原题库。

题单与学习记录一起保存、备份和导入导出。保存题单只更新题单字段，并与笔记写入依次处理，避免覆盖独立窗口刚保存的笔记。

## 升级与安装

提供 Windows x64 安装版及便携版、Linux x64 AppImage 及 Debian 包、macOS Intel 及 Apple Silicon 包。Windows 安装版可在“数据中心 → 应用更新”检查和下载安装，其余版本按既有方式手动更新。升级保留本地学习数据。

正式附件在核心回归、各平台构建与启动检查、下载完整性验证及 Windows 覆盖升级检查通过后公开。

## English summary

- Add local templates to the study plan and open their original files in VS Code from either window, including after switching between selected template folders.
- Track cumulative template review completions. Undoing completion reverses the current round; reviewing again adds another round, and deleting a queue entry keeps the total. Existing completed templates migrate as one recorded completion.
- Append new study-plan entries in insertion order while retaining manual reordering after the initial migration.
- Create named personal problem lists, collect problems into multiple lists, filter, rename, remove entries and delete lists. Lists persist with study data and backups.
- List updates preserve notes saved in other windows, with concurrent list and note writes handled in sequence.
