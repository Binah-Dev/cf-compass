已在 [CF Compass v4.1.1](https://github.com/Binah-Dev/cf-compass/releases/tag/v4.1.1) 中修复，感谢这次反馈！

- 普通比赛榜单请求改为仅包含 `contestId` 的匿名 GET，不再发送旧版虚拟榜单筛选参数。
- 展开虚拟场次可正常打开题目和加入补题；估分是独立的手动操作，不再阻塞复盘。
- 本场估计分通过完整场内提交重建成绩，校验计分规则，再插入当前能匹配到的原比赛 Rated 选手榜单进行 Carrot 计算。不会混入赛后补题或其他虚拟场次。
- 估计分和参考位次不等于官方虚拟排名，不改变正式 Rating，也不进入总体表现统计。若当前榜单与历史 Rated 记录不一致，会显示匹配人数；缺失选手不会被编造为零分。特殊计分、未完成判题、无法可靠还原的 CF 重复提交等情况会明确提示限制。

此回复仅在四平台构建、macOS 原生签名与启动检查、发布资产重新下载校验，以及 Windows 安装/便携版冷启动验证通过后发送。
macOS 使用 ad-hoc 签名，并非 Apple Developer ID 公证。

请使用完整 Setup 安装包升级；如某一场仍提示规则无法还原，欢迎附比赛编号和不含敏感信息的错误提示继续反馈。
