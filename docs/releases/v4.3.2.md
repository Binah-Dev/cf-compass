# CF Compass v4.3.2

v4.3.2 新增计划题单计时表，在独立辅助窗口提供正向、反向和定点计时。保留中英文界面、本地优先架构，以及 v4.3.1 的自定义训练赛、独立隐藏标签与难度、Windows 安装版更新和专属侧栏图标。

## 计划题单计时表

在 **计划题单 → 计时表** 打开辅助窗口；独立题单窗口也提供计时入口。重复打开会显示已有窗口，全局同时保留一只计时表，不改变题单完成记录、训练成绩或 Rating，也不新增云同步或计时统计。

- **正向计时**：开始、暂停、继续和重置，累计时间可超过 24 小时。
- **反向计时**：设置 1 秒至 7 天的时长，支持暂停、继续和重置；到时显示完成提示。
- **定点计时**：设置未来 366 天内的本地日期与时刻，显示跨日日期和时区。开始后目标时刻固定，不提供暂停；取消后可修改。
- 运行中或暂停时，先重置或取消才能修改模式与设置。点击开始后保存设置与计时状态；**尚未开始的输入只在当前窗口内，关闭后不保留**。操作落盘后才更新状态，重复点击不会创建额外计时器。

## 定点提醒与本地音频

**只有定点计时播放声音；正向与反向计时保持静音。** 定点模式使用程序生成的温和短铃声，也可通过系统文件选择框设置本地音频，试听或停止播放。

- 试听与到时播放均最多 15 秒，不循环；取消、重置、切换模式或点击停止会停止声音。同一次到时不会因普通刷新或重复轮询反复响铃。
- 支持选择 WAV、MP3、OGG、M4A、AAC、FLAC，单文件上限 **20 MiB**。解码能力取决于当前 Electron 和系统；自定义音频无法播放或保存副本缺失时，尝试默认铃声并显示提示。
- 音频复制到本地应用数据，原文件之后移动不影响已保存副本；不上传音频。系统静音、音量和通知设置仍可能影响提示。

## 关闭、退出与休眠边界

切换页面、最小化主窗口或关闭计时表窗口均不会暂停计时；应用仍运行时，关闭辅助窗口后定点到时仍可响铃。退出整个应用后，运行中的计时按现实经过时间恢复，暂停的计时保持暂停；重新启动时恢复状态，已到时的计时补完成提示。

**应用完全退出时不能播放声音；系统休眠时不能保证准时响铃。** 恢复运行后按系统时间校准并检查到时，不会唤醒电脑或自动启动应用。手动调整系统时钟仍会影响时间计算。此功能是应用内学习辅助工具，不是系统级闹钟。

计时状态与音频副本保存在本机，独立于学习数据；目前不随学习数据 JSON 导入、导出或备份迁移。完整用法见 [计时表说明](../study-timer.md)。

## 已有功能与升级

自定义训练赛继续支持从题库、收藏与目标题单组题，独立隐藏标签和难度，并按绑定账号、完整题号和本场提交时间同步结果；自组训练不并入官方或综合估计 Rating。Windows x64 安装版继续在 **数据中心 → 应用更新** 检查公开稳定版，下载和安装需明确操作，进行中的自定义训练阻止安装。

Windows 内置更新从 v4.3.1 起提供。v4.2.2 及更早版本需要先手动安装支持更新的官方 `Setup.exe`；便携版、解包目录和其他平台继续手动更新。AppImage 仍通过外部更新工具使用匹配的 `.zsync`，不在应用内自动更新。详见 [v4.3.1 功能说明](./v4.3.1.md) 与 [Windows 更新说明](../windows-auto-update.md)。

## English summary

- Adds **Study Plan → Timer**, also available from the separate plan window. Repeated opens focus the same auxiliary window; one timer is shared across the application.
- Provides **stopwatch**, **countdown** (1 second to 7 days), and **target-time** (a local date/time within the next 366 days) modes. Stopwatch and countdown support pause/resume; fixed target-time mode uses cancel/edit instead of pause.
- Only target-time mode plays sound. It supports a short default bell or a local audio copy up to **20 MiB**, with preview/stop and a maximum **15-second, non-looping** playback. Unsupported or missing custom audio falls back to the default bell. Stopwatch and countdown remain silent.
- Starting persists the timer. **Unstarted form inputs are not retained after closing the window.** Closing the auxiliary window does not pause an active timer; restarting restores running elapsed time or a paused state.
- No sound can play while the application is fully exited, and sleep cannot guarantee a punctual alarm. Recovery recalibrates from the system clock and shows missed completion. The feature does not wake the computer or start the application automatically; clock changes can affect timing.
- Timer/audio data stays local, separate from learning-data imports, exports, and backups. The feature adds no cloud sync, statistics, or Rating changes.
- Retains v4.3.1 Custom Training, independent tag/Rating visibility, the dedicated rail icon, and Windows installer updates. Windows updating first became available in v4.3.1; portable and other-platform editions still update manually.
- Keeps the nine-asset platform inventory above, with no standalone `.sha256` or `SHA256SUMS.txt` attachments. Internal CI verification and updater metadata hashes remain intact.
- Local validation passed 34 timer/audio regression tests and 12 isolated real Windows Electron UI flows. New timer interactions were not locally verified on native Linux/macOS. Tagged packages must pass the platform, launch, download, and Windows installation gates before publication; these checks do not guarantee every audio codec or timely alarms during sleep.
- Windows remains unsigned, macOS is ad-hoc signed and not notarized, and Linux retains its documented Chromium sandbox and restricted Ubuntu 24.04 AppArmor requirements. Historical updater and platform evidence does not replace verification of these packages.
