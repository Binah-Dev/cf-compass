# CF Compass v4.1.2

完整正式安装包，包含 v4.1.1 的功能，本次重点修复赛事复盘保存与推荐题单，并完善标题栏。

## 赛事复盘与推荐题单（Issue #27）

- 修复增强复盘保存时丢失源码时间线和 Diff 展示数据的问题；重新打开或重启后复用已保存报告，不再因为缺少旧版明细自动请求 AI。
- 保存真正成功后才显示已保存；切换场次、关闭窗口或重新请求时，过期结果不会覆盖当前场次。
- 旧版已经丢失的源码明细无法从报告正文恢复，但正文仍可查看；需要明细时可手动重新分析。
- 从已同步题库按题号补齐比赛题目缺失的 Rating 和标签，提高相似题筛选的可靠性；不改变排序权重，不编造缺失数据。
- 分别解释未同步题库、题目元数据不足和没有合适未做题三种情况；本地题库指“题库工作台 → 同步数据”，不是本地模板文件夹。
- 未知时间不再显示为零秒，Diff 保留缩进与上下文空格，过长内容明确标记截断。

## 顶部标题栏与外观

- 顶部使用铺满窗口的单一实色色块，消除叠层黑条和露底；默认跟随天空蓝、薄荷绿、珊瑚粉主题。
- 外观设置支持独立调节标题栏颜色，浅色背景自动使用深色文字；支持预览、取消、保存和恢复跟随主题。
- 标题栏独立于内容面板透明度；沉浸大厅时隐藏并禁用隐藏窗口控件，退出后恢复。
- 补齐部分英文界面和无模板时的提示。

## 验证与使用说明

发布前执行逻辑测试与真实 Electron 界面回归，覆盖保存/重启、延迟响应、保存失败、虚拟赛、补题、布局、主题、素材和小字可读性；发布流程另验证 Windows、Linux、macOS Intel/Apple Silicon 原生包与 SHA-256，并重新下载验证 Windows 安装/冷启动。

AI 回归使用模拟服务，未调用付费 AI；不同服务商及反馈者原始数据仍可能存在未覆盖情况。如仍能复现，请补充步骤与脱敏错误信息，不要上传 API 密钥。

包含 Windows x64 Setup/portable、Linux x64 AppImage/deb、macOS x64/arm64 dmg、单包 SHA-256 和总清单。Windows 日常使用推荐 Setup，升级前建议导出备份。安装包不包含第三方壁纸、个人素材、用户数据或 API 密钥。

macOS 使用 ad-hoc 签名，不是 Apple Developer ID 公证；首次运行可能需要在系统隐私与安全设置中确认。
