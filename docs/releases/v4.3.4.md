# CF Compass v4.3.4

修复 [#45](https://github.com/Binah-Dev/cf-compass/issues/45)：部分虚拟赛因 Codeforces 提交时间字段相差 1 秒，整场显示“提交时间处于场次边界或不一致，暂不估分”。现在允许绝对提交时间与相对时间存在 **±1 秒**取整偏差，正常场内提交可以继续计算本场参考分与参考位次。

升级后，在 **赛事复盘 → 虚拟参赛** 展开此前失败的场次，点击 **重新估分**。参考分仍是本地估计，不修改官方 Rating。

## 计分与数据校验

- 校验与计分使用同一个绝对提交时间。若 1 秒变化跨过分钟边界，CF 分数衰减和 ICPC 罚时按该绝对时间所属分钟计算。
- 虚拟场次起点继续精确匹配；不同场次、练习提交和场外提交不会因此混入。
- 负时间、恰好到达比赛结束边界、非整数时间、超过 1 秒的字段偏差，以及不完整身份、未完成判题和不支持的计分规则仍保留拒绝保护。
- 本版也包含 v4.3.3 之后主线合入的 Codeforces 同源传输加固。

## 构建与升级

沿用现有发布门禁：核心回归、四种平台原生构建、打包启动检查、附件下载与摘要回验，以及 Windows 安装版、便携版和上一稳定版覆盖升级验证。正式包通过门禁后才公开，候选说明本身不表示这些检查已经完成。

提供 Windows x64 安装版 / 便携版、Linux x64 AppImage / Debian 包、macOS Intel / Apple Silicon 包，以及 `latest.yml`、Windows `.blockmap` 和 AppImage `.zsync` 更新数据。Windows 安装版可在 **数据中心 → 应用更新** 更新；其他版本继续手动更新。平台安装条件沿用既有说明。

## English summary

- Fixes #45: a **±1-second** rounding difference between Codeforces absolute and relative submission timestamps no longer makes a complete virtual session unavailable for estimation.
- Validation and scoring share the absolute submission time. Minute-boundary changes use that timestamp for CF decay and ICPC penalties.
- Exact virtual-session identity, contest boundaries, integer timestamps, larger discrepancies, participant identity and scoring-model checks remain enforced.
- After upgrading, open the affected virtual replay and click **Recalculate estimate**. Estimates do not change official Rating.
- Includes the Codeforces same-origin transport hardening already merged after v4.3.3. Tagged packages are published only after the existing build, launch, download-integrity and Windows previous-stable upgrade gates pass.
