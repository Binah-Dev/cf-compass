# CF Compass v4.0.0

CF Compass v4.0.0 把“找到题”升级为“复盘比赛—定位薄弱点—收到真实推荐—加入目标—完成并留下笔记”的完整训练闭环。这个版本正式接收 Yunlk 的 [PR #16](https://github.com/Binah-Dev/cf-compass/pull/16)，并在其 AI 赛事源码复盘基础上补齐桌面交互、真实题库推荐、全局笔记、目标题单与持久化可靠性。

## 全新桌面 UI

- 左侧功能栏采用更接近 VS Code 的交互：可通过右键隐藏或恢复入口，也可以拖动调整相对位置。
- 赛事复盘改为覆盖当前页面的全页二级界面，减少窄侧栏造成的信息拥挤。
- 赛事列表、比赛题目、AI 复盘、推荐卡片与设置页统一跟随外观设置中的小、中、大字号，不再各自维护一套偏小字体。
- 薄弱项训练卡片与其他题目卡片使用一致的编号、Rating、操作按钮和信息层级。

## AI 赛事复盘与源码增强复盘

- AI 赛事复盘基于本场比赛真实提交序列、通过情况、耗时与错误转折生成总结。
- 源码增强复盘可拉取用户自己的 Codeforces 提交源码，按时间线展示 WA 到 AC 的代码 Diff，帮助定位真正发生变化的逻辑。
- DeepSeek V4 等可能返回结构化内容的模型响应会被正确解析，不再出现“AI 没有返回可用内容”的误报。
- 当 API、源码权限或模型响应不可用时，界面提供明确失败信息，不把缺失数据伪装成分析结论。

## 真实题库驱动的赛后推荐

- 推荐只使用本地已经同步的 Codeforces 题库，不凭空编造题号、题名或标签。
- 失败次数、WA→AC 转折、异常耗时、未通过题、下一题难度与知识点相似度都会成为可检查的推荐依据。
- 候选生成先执行硬过滤：排除本场原题、已解决题、已在计划中的题、重复题、无效题和缺少必要标签的题，再进行评分与排序。
- 推荐卡片显示索引、Rating、匹配理由，并支持直接打开题目、收藏、写笔记或加入目标题单。
- 代表性与对抗性回归覆盖 WA→AC、慢速 AC、未通过/边界题、重复项和虚构题号；12,000 题候选集的本次本地实测 P50 为 18.88 ms、P95 为 41.65 ms。

## 全局笔记本

- 题库工作台、今日训练、复习库时间轴、赛事题目、AI 推荐和目标题单均可直接打开同一套题目笔记。
- 笔记按题目标识持久化，主窗口与独立题单窗口会同步更新。
- 完成题目后可以保留解题思路、错误原因和下次复习提示，不再需要跳回单独页面寻找入口。

## 目标题单

- 各主要题目入口均可将题目加入待做队列，并显示清晰的计划编号。
- 题单既可作为主页面使用，也可打开为独立的二级窗口；窗口支持拖动、调整大小和离开主窗口单独摆放。
- 队列支持拖拽排序。点击完成圆圈后题目会划线但保留在队列中；需要移除时再点击垃圾桶。
- 计划数据采用本地持久化，并包含在手动导入、导出和自动备份中。

## 可靠性修复

- 修复模板库保存的题意在刷新、重启、切换模板目录或配置损坏后消失的问题。题意现在按模板根目录保存，写入过程使用临时文件替换，并保留可恢复备份。
- 修复赛事复盘页面因缺少收藏数据而打开黑屏的问题。
- 修复沉浸大厅启用后主页面向左平移的问题；背景只负责视觉覆盖，不再改变应用内容层的 x/y/宽/高。
- 修复 AI 配置区、原赛事页面和复盘页面字号不一致，以及薄弱项推荐卡片与常规题目卡片不一致的问题。

## English summary

CF Compass v4.0.0 delivers a complete contest-to-training loop: full-page AI contest review with real submission timelines and source diffs, evidence-based recommendations selected only from the locally synced Codeforces problemset, a persistent cross-page notebook, and a detachable, resizable, sortable study-plan window. It also unifies desktop typography and rail customization, preserves template statements across refreshes, restarts, folder switches and damaged configs, fixes contest-review black screens and DeepSeek V4 parsing, and removes the immersive-lobby layout shift.
