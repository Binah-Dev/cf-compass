# CF Compass v4.1.1

完整正式版本，包含 4.1.0 功能以及以下修复和外观返工；不是增量补丁文件。

## 复盘与 Codeforces 接口兼容

- 普通比赛榜单统一使用匿名 GET，且只带比赛编号，修复虚拟参赛复盘、赛事中心详情的 HTTP 400 错误。
- 升级后允许旧参数错误的记录重新尝试；明确的客户端错误不再无效重试，请求具备超时边界。
- 虚拟赛专注复盘和补题：展开场次即可查看题目、打开原题、加入补题队列；本场提交和场内 AC 与赛后补题分别统计。
- **虚拟赛本场估计分**：点击计算时读取完整本场提交，校验原比赛计分模型，将重建成绩插入当前可见的原比赛 Rated 选手榜单后计算 Carrot 参考分。参考位次不是官方虚拟排名，不进入正式 Rating 或总体统计。离线保留已有结果；特殊计分、未完成判题、无法还原的 CF 重复提交等情况明确拒绝估分，不影响题目打开与补题。
- 当前公开榜单与历史 Rating 记录可能不完全对应；只采用可匹配选手，并显示匹配人数及缺失提示，不将缺失选手编造为零分。因此本场估计分不是完整历史榜单的精确复算。
- **顶部标题栏整理**：背景铺满到窗口顶部，不再保留 34 像素的露底空隙；按反馈保留整条统一的半透明深色标题栏，去除多余阴影和装饰条，保留拖动、窗口控制和内收的键盘焦点提示。标题栏独立于内容面板透明度，保证窗口操作清晰。
- 标题栏跟随三套主题色；进入沉浸大厅时隐去并禁用隐藏窗口按钮与拖动区域，退出后恢复，保留 Esc 与返回终端入口。
- 有完整本地比赛缓存时直接使用；缺少缓存时按公开接口获取题目。切换场次时各场独立加载，不再因另一场正在加载而跳过当前场次。

官方规则：[contest.standings](https://codeforces.com/apiHelp/methods#contest.standings)。

## 共享大厅与三套主题

- 面板透明度方向与名称一致：0% 不透明，100% 去掉面板底色与磨砂，文字和按钮仍可操作。
- 统一主界面各页的面板、内层表格和固定渐变；独立调节磨砂、阴影和背景遮罩。
- 平衡、专注和展示预设，数字输入、单项重置，以及保存自己的方案。
- 实时预览不混入其他数据保存：完成才保存，取消、关闭和 Esc 撤回试调。导入/删除素材仍属于独立的明确操作。
- 天空蓝、薄荷绿、珊瑚粉统一按钮、选中态和轻微面板染色；AC、错误、Codeforces Rating 颜色保持语义。
- 移除多余的“显示面板”入口和重复的“算法分类 / 题目列表 / 个人进度”标题行。保留原有标题，移动和展开收为角落图标，边角缩放、键盘微调、布局记忆和智能复位仍可用。

## 完整安装包与数据

包含 Windows x64 Setup 安装版与 portable 便携版、Linux x64 AppImage 与 deb、macOS Intel 与 Apple Silicon dmg，以及各包 SHA-256 和总校验清单。

Windows 日常使用推荐 Setup。升级前建议导出备份。安装包不含第三方壁纸或用户素材，也不携带用户数据/API 密钥。

macOS 为 ad-hoc 签名，**不是 Apple Developer ID 公证**，首次打开可能仍需在“隐私与安全性”中确认。

全透明展示不保证任意亮色背景上的文字对比度；持续阅读建议使用平衡或专注预设。真实素材在独立本地副本中测试，不进入发布包。
