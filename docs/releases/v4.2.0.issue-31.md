已在 [v4.2.0](https://github.com/Binah-Dev/cf-compass/releases/tag/v4.2.0) 实现并通过发布验证，感谢建议！

- 默认官方模式；主页个人进度的 Rating 选项可切换本地估算模式，让有历史 Rated 对照数据的虚拟赛逐场影响训练参考分。
- 「今日训练 → 训练偏好」支持手动参考 Rating（800–3500）。手动设置在官方模式下生效；估算模式使用累计估算分。
- 估算账本标记缺失、不可用与排除场次，可重试；不覆盖官方 Rating。重复参赛与原题接触仍计入并提示，无可见提交的场次无法发现。

跨平台构建、包校验和 Windows 安装/冷启动验证通过后发布。如有异常欢迎附上脱敏复现步骤，勿上传密钥或个人备份。
