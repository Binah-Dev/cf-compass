这是一次面向中英文用户首次体验的补丁版本。中文用户的现有体验保持不变，同时减少国际用户第一次打开应用时的语言和布局障碍。

## 更新内容

- 首次启动现在跟随系统语言：中文系统默认显示简体中文，其他系统默认显示 English。
- 已经保存过语言选择的用户不会被系统语言覆盖；升级后仍沿用原来的界面语言。
- 修复英文“今日训练”复习卡片中算法标签被挤成单个字母的问题，较长标签会在卡片内自然换行并保持可读。
- 修复英文天数的单复数显示，`1 天` 现在正确显示为 `1 day`，其他数量继续显示为 `days`。
- 新增首次启动回归检查，覆盖英文新用户、中文新用户，以及英文系统上的既有中文用户。

## English summary

CF Compass now follows the system language on first launch: Chinese systems start in Simplified Chinese, while all other systems start in English. Existing users keep their saved language preference. This release also fixes compressed English tags in Today's Training, corrects `1 day` versus `days`, and adds regression coverage for fresh Chinese and English profiles plus existing-user preference preservation.
