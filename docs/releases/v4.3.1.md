# CF Compass v4.3.1

v4.3.1 新增自定义训练赛第一版、Windows 安装版更新，以及专属的自定义训练赛侧栏图标。保留中英文界面、本地优先数据架构和原有训练、复盘与综合估计 Rating 功能。

## 自定义训练赛

- 从题库、收藏或目标题单挑选题目，查看已有尝试与通过记录，设置顺序、时长和标题，保存草稿或开始训练。
- **隐藏标签**与**隐藏难度 Rating**分别控制，训练与结果页沿用各自的会话设置；需要复盘时可分别展开。跳转 Codeforces 原站仍可能看到官方标签和难度。
- 开始后锁定账号、题目顺序、时长和隐藏设置，显示倒计时与未尝试、错误、判题中、通过状态。会话持久化，退出应用后计时继续，重启可恢复。
- 使用绑定账号在 Codeforces 原站提交，再同步本场结果。只统计该账号的单人 `PRACTICE` 提交，完整匹配 `contestId + index`，并使用提交 `creationTimeSeconds` 与本场绝对时间窗口；不使用原比赛 `relativeTimeSeconds`。
- 同步按提交 ID 去重，断网保留已有结果，恢复网络后可补同步。截止前提交、截止后出结果仍可更新；判题中不算错误或通过。切换账号不能将另一账号的提交计入原会话。
- 到时或提前结束后展示通过数、首次 AC 用时、错误尝试与待补题，复用已有笔记和计划题单入口。取消保留取消状态及已同步记录；重复操作不会重复创建正在进行的会话。

自组训练独立于官方比赛和 Codeforces virtual，不并入官方或综合估计 Rating。第一版不提供自建判题器或多人排行榜。计时依赖系统时钟，Codeforces 数据和判题结果可能延迟，必要时再次同步。详见 [自定义训练赛说明](../custom-training.md)。

## Windows 安装版更新

- Windows x64 `Setup.exe` 安装版在 **数据中心 → 应用更新** 检查本仓库的公开稳定版，展示版本、发布说明和下载进度。
- 默认启动检查可关闭；**下载需主动点击，安装需明确确认退出应用**，不会自动下载或退出安装。正在进行自定义训练赛时阻止安装，升级保留本地学习数据。
- 下载可取消，检查或下载失败后可重试；只接受更高的稳定版本及匹配的完整 NSIS 安装包，保留 SHA-512 校验。暂不启用差分下载。
- 便携版、解包目录、开发环境、浏览器和其他平台保留手动发布页入口。

**Windows v4.2.2 及更早版本没有此更新入口，需先手动安装一次 v4.3.1 的 `Setup.exe`。** 之后才可通过内置更新获取后续稳定版。详见 [Windows 更新说明](../windows-auto-update.md)。

## 专属侧栏图标

自定义训练赛入口改为原生 SVG「秒表＋播放符号」，与赛事中心的日历图标区分。尺寸、线条粗细、继承配色及默认、悬停、选中样式与现有侧栏保持一致。

## 面板透明度

修复自定义训练赛与应用更新卡片的背景，使其沿用现有面板透明度设置。

本地已验证训练会话回归、真实 Electron 中英文训练与更新流程、侧栏图标状态，并通过隔离 NSIS fixture `0.0.1 → 0.0.2` 的实际升级、错误 SHA-512 拒绝及数据保留测试。fixture 使用本机 loopback 源和独立应用身份，不能证明生产 GitHub 渠道向未来公开版本的升级。正式标签构建须重新打包并通过各平台构建、Linux 启动、下载回验和 Windows 安装/便携版门禁后才公开 Release；[v4.2.2 的 Linux 验证](./v4.2.2.md) 是历史记录，不代替本版产物验证。

Windows 包尚无商业 Authenticode 签名，SmartScreen 可能显示未知发布者；SHA-512 校验验证文件与元数据一致性，不等同发布者身份认证。macOS 包使用 ad-hoc 签名，未经过 Apple 公证。Linux 保留 Chromium 沙箱：Ubuntu / Debian 推荐 `.deb`，受限制的 Ubuntu 24.04 AppImage 仍需固定路径和管理员批准的 AppArmor 配置，详见 [Linux 安装说明](../linux-appimage.md)。不声明任意 Linux 主机均可直接运行。

## English summary

- Adds **Custom Training** from the problem library, favorites, or study plan, with previous-solving hints, problem order, duration, and saved drafts. Starting locks the session; persisted state and the absolute countdown survive restart.
- **Hide tags** and **hide Rating** are independent settings retained in training and results, with explicit reveal controls for review. Codeforces pages retain their original information.
- Submit on Codeforces with the bound account. Only that account's solo `PRACTICE` submissions count, matched by the complete problem ID and `creationTimeSeconds` within this session's window. Original contest-relative times are not reused.
- Deduplicates submissions, preserves results offline, supports later synchronization and verdicts arriving after the deadline, and prevents cross-account counting. Results show solved count, first AC time, wrong attempts, and unsolved problems, with shared notes and study-plan actions.
- Custom sessions remain separate from official/virtual contests and never enter official or combined estimated Rating. Version one includes no private judge or multiplayer leaderboard. Timing depends on the system clock and public API data can be delayed.
- Adds **Windows x64 NSIS installer updates** under **Data Center → App Updates**, using this repository's stable GitHub releases. Startup checks can be disabled; downloading requires a click and installation requires explicit confirmation. Active training blocks installation. Full-installer downloads retain SHA-512 verification; differential downloading is disabled.
- **Windows v4.2.2 and older need one manual installation of the v4.3.1 `Setup.exe` first.** Portable, unpacked, development, browser, and other-platform editions still update manually.
- Gives Custom Training a dedicated native SVG stopwatch-and-play rail icon with the existing size, stroke, colors, and interaction states.
- Fixes Custom Training and App Updates card backgrounds to follow the existing panel transparency setting.
- Preserves the existing platform matrix and publishes exactly the nine assets listed above. No standalone `.sha256` or `SHA256SUMS.txt` attachments are uploaded; private CI verification and the updater's metadata hashes remain intact.
- Local Electron flows and a real, isolated NSIS `0.0.1 → 0.0.2` fixture upgrade passed, including invalid SHA-512 rejection and data retention. The loopback fixture does not establish a future public GitHub-channel upgrade. Tagged packages must be rebuilt and pass the CI platform, launch, download, and Windows installation gates before publication; historical v4.2.2 Linux evidence does not validate the new packages.
- Windows remains unsigned; macOS is ad-hoc signed and not notarized. Linux preserves the Chromium sandbox, and restricted Ubuntu 24.04 AppImage use requires the documented administrator-approved fixed-path AppArmor configuration. Universal Linux compatibility is not claimed.
