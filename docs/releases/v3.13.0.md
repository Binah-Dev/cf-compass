CF Compass 3.13.0 是 3.13 系列的正式稳定版本。它完整保留题库工作台、今日训练、间隔复习、赛事中心、赛事复盘、本地模板库、Codeforces 自动同步和中英文界面，并正式交付高清/动态记忆大厅、素材质量隔离、增量性能优化与更严格的跨平台发布验收。

## 完整训练工作流

- 题库工作台支持题目状态、算法标签、Rating 区间、收藏状态与通过次数筛选。
- 今日训练综合当前 Rating、薄弱算法、历史练习和复习计划生成分层题单。
- 复习库保留刷题记录、间隔复习计划与可视化时间轴，方便重新练习真正有价值的历史题目。
- 赛事中心可以检索并筛选 Codeforces 场次；赛事复盘集中展示表现分、实际排名、Rating 变化、赛时通过情况和赛后补题状态。
- 本地模板库按照完整算法体系整理源码，支持分类、搜索、结构化题意摘要与直接在 VS Code 中打开。
- Codeforces 数据支持手动和自动同步；简体中文与 English 界面会尊重用户已经保存的语言选择。

## 高清与动态记忆大厅

- 支持 PNG、JPG、WebP 静态图片，以及 MP4、WebM 动态背景。
- 单张静态图片最高支持 160 MB，单个动态背景最高支持 2 GB。
- 提供智能填充、全屏裁切与完整显示三种布局，兼顾无黑边、人物主体和不同屏幕比例。
- 高清原图与最长边 1280px 的轻量预览分离：素材浏览优先使用预览，真正显示时再加载原始资源，减少大图解码和内存浪费。
- 动态背景支持 `0.5×–1.5×` 播放速度；窗口失焦、最小化、页面隐藏或开启“减少动态效果”后会自动暂停。
- 素材服务会统一隔离已知拆包碎片，以及标记为 `layer`、`sprite`、`thumbnail`、`transition` 或 `wallpaperReady: false` 的非壁纸资源；旧选择失效时会安全回退。
- 第三方图片、人物素材、模板源码和用户数据不会进入公开源码、安装包或云端同步。

## 架构与性能优化

- 背景渲染、素材导入、素材库读取和质量判断拆分为独立模块，后续增加格式或导入方式不需要在多个页面重复修改。
- 素材索引按照文件大小与修改时间复用缓存，旧素材的轻量预览按需生成，避免每次启动重新处理全部高清文件。
- 首屏优先恢复训练数据，背景和排名等次要信息延后加载，降低启动阶段的资源争抢。
- 最近活动在 Codeforces 返回正常倒序数据时跳过重复排序，外部乱序数据仍会自动回退到完整排序。
- 性能优化不以删减题库、复习、赛事、模板或双语功能为代价，现有训练能力完整保留。

## 页面稳定性修复

- 修复 [Issue #13](https://github.com/qeffg/cf-compass/issues/13)：首次更换 Handle 并同步后，多年份热力图不再推动整个应用横向滚动。
- 年份切换只调整热力图内部年份条，不再滚动根页面；左侧导航不会被裁掉，右侧也不会出现大片空白。
- 已覆盖 2560×1600 窗口和 2016–2026 共 11 年数据的初始、最早年份与最新年份状态。

## 正式版发布验收

- 源码测试、生产依赖安全审计以及 Windows、Linux、macOS Intel、macOS Apple Silicon 原生构建必须全部成功。
- Windows 解包版必须通过素材隔离、训练主流程和多年份布局回归。
- macOS Intel 与 Apple Silicon 应用分别在原生架构运行器上构建，并执行深度签名验证和真实进程存活测试。
- 发布后的 Windows portable 必须重新从 GitHub Release 下载、匹配 `SHA256SUMS.txt`，并在隔离用户数据目录中真实冷启动出 CF Compass 主窗口。
- 任一构建、校验或启动步骤失败都会阻止本正式版被视为完成。

## 下载

- Windows x64：`CF-Compass-3.13.0-Windows-x64-portable.exe`
- Linux x64：`CF-Compass-3.13.0-Linux-x86_64.AppImage`
- Debian / Ubuntu x64：`CF-Compass-3.13.0-Linux-amd64.deb`
- macOS Intel：`CF-Compass-3.13.0-macOS-x64.dmg`
- macOS Apple Silicon：`CF-Compass-3.13.0-macOS-arm64.dmg`

每个程序包均附带独立 `.sha256`，同时提供完整的 `SHA256SUMS.txt`。请下载与系统匹配的程序包，不要把 GitHub 自动生成的 `Source code.zip` 当作可运行软件。

## 签名与素材边界

- Windows 构建尚未购买商业代码签名证书，因此 SmartScreen 可能显示“未知发布者”；请只从本仓库 Release 下载并核对 SHA-256。
- macOS 应用使用可验证的 ad-hoc 签名，但没有 Apple Developer ID 签名或公证；部分系统仍可能要求在“隐私与安全性”中确认打开。
- 仓库和 Release 只分发原创代码、应用图标与程序包，不重新分发第三方游戏图片、人物素材或维护者本地数据。

## English summary

CF Compass v3.13.0 is the stable 3.13 release. It preserves the complete problemset, daily training, spaced review, contest search and review, local template library, Codeforces synchronization, and bilingual interface while delivering high-resolution image and MP4/WebM lobby backgrounds, safer local asset handling, incremental startup and indexing improvements, and the verified Issue #13 viewport fix.

Windows, Linux, macOS Intel, and macOS Apple Silicon packages include individual checksum files and a complete `SHA256SUMS.txt`. The release pipeline builds each native package, validates the unpacked Windows application and macOS signatures, then downloads the published Windows portable package again for checksum verification and an isolated cold start.
