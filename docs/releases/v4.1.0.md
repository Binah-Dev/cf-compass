# CF Compass v4.1.0

## 虚拟赛与补题

- 支持虚拟参赛复盘，以比赛 ID 和本次虚拟赛开始时间隔离场次，避免多次练习混在一起。
- 展示本场参考表现分，标明为非官方估算；不计入正式 Rating、总体表现和正式排名统计。资料不足或不支持的赛制明确提示，不伪造结果。
- 修复未参加的比赛加入补题后列表为空的问题。补题队列保存题目快照，离线和重启后仍可查看。
- 保存采用原子替换；失败时保留原文件，避免半写入数据。

## 更跟手的桌面工作台

- 题库三个面板可自由拖动、八方向调整大小、单框展开和还原，布局自动记忆；智能复位同时恢复位置与尺寸。
- 拖动按刷新帧合并处理，位置更新不添加滞后动画；搜索输入优先响应。
- 优化 Rating 历史图范围拖动，减少重复布局读取；模板卡片每批显示 60 项，搜索仍覆盖完整模板库。
- 统一短反馈与页面过渡，尊重系统及应用的减少动态效果设置；修复窗口缩放和焦点导致外壳意外偏移。
- 普通说明文字可读性优化；导入素材的分类仅保留“全部”，不删除素材或收藏。

## 下载与数据

提供 Windows x64 安装版/便携版、Linux x64 AppImage/deb、macOS Intel/Apple Silicon dmg，以及 SHA-256 校验文件。

Windows 日常使用推荐安装版：便携版每次启动都需要解压。升级前建议在数据中心导出备份。安装包不包含第三方壁纸、角色图片及用户本地素材。

macOS 使用 ad-hoc 签名，不是 Apple Developer ID 公证，首次打开可能需要在“隐私与安全性”中确认。

## 验证边界

本版增加场次隔离、虚拟参考分、自由布局、指针帧调度、模板分批展示和素材分类的回归检查。性能测试使用构造数据，减少重复工作的测量不等同于所有设备的固定帧率承诺。
