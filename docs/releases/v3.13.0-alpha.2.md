# CF Compass v3.13.0-alpha.2

这是一个用于公开验收的 Alpha 预发布版本，完整继承现有题库、复习、今日训练、赛事中心、赛事复盘、模板库、自动同步和中英文界面，并重点升级记忆大厅与发布可靠性。

## 功能与架构优化

- 记忆大厅支持“智能填充、全屏裁切、完整显示”，可使用最高 160 MB 的 PNG/JPG/WebP 高清图片和最高 2 GB 的 MP4/WebM 动态背景。
- 动态背景支持 `0.5×–1.5×` 播放速度，并会在窗口失焦、最小化、页面隐藏或开启“减少动态效果”后暂停。
- 自定义静态背景保留高清原图，同时生成最长边 1280px 的轻量预览；旧素材库按需生成预览并复用缓存。
- 图片/视频渲染、背景导入、素材库读取和素材质量策略已经拆为独立模块，后续扩展格式或导入方式不需要在多个页面重复修改。
- 素材库会统一隔离已知不完整拆包图层，以及声明为 `layer`、`sprite`、`thumbnail`、`transition` 或 `wallpaperReady: false` 的非壁纸资源；旧选择会自动回退到安全大厅。
- 最近活动针对正常倒序提交跳过重复排序，素材清单按文件大小与修改时间缓存，首屏优先恢复训练数据，背景等次要信息空闲加载。

## Issue 修复

- 修复 [#13](https://github.com/qeffg/cf-compass/issues/13)：首次更换 Handle 并同步后，多年份热力图不再带动整个应用横向滚动，左侧导航不会被裁掉，右侧也不会出现大片空白。
- 年份切换只修改热力图年份条自身的 `scrollLeft`，不再使用可能滚动根页面的 `scrollIntoView`。
- 2560×1600、2016–2026 共 11 年的专项回归验证：初始、最早年份、最新年份三个状态下，应用画布均覆盖完整窗口，根页面保持 `scrollX = 0`，左侧栏稳定处于 `0–68px`。

## Alpha 2 验收修正

- Windows 云端主功能验收固定使用 1920×1080 桌面视口，不再把窄屏响应式布局中正常隐藏的个人进度卡误判为失败。
- 动态背景回归现场生成确定性的 1920×1080 原图和 1280×720 预览，避免测试素材宽高比漂移。
- Release 只有在原生 Windows 包发布后重新下载、SHA-256 一致、冷启动、主功能、素材隔离和多年份布局全部通过时，才会回复并关闭 Issue。

- Linux x64：`CF-Compass-3.13.0-alpha.2-Linux-x86_64.AppImage`
- Debian / Ubuntu x64：`CF-Compass-3.13.0-alpha.2-Linux-amd64.deb`
- macOS Intel：`CF-Compass-3.13.0-alpha.2-macOS-x64.dmg`
- macOS Apple Silicon：`CF-Compass-3.13.0-alpha.2-macOS-arm64.dmg`

每个程序包均附独立 `.sha256`，同时提供完整 `SHA256SUMS.txt`。Windows 包尚未使用商业代码签名；macOS 包使用可验证的 ad-hoc 签名，但未经过 Apple Developer ID 公证。

第三方人物图片、记忆大厅素材和用户本地数据不会进入源码仓库或安装包。应用只保存用户自行导入的本地素材引用与缓存。

CF Compass v3.13.0-alpha.2 is a public preview with high-resolution and video lobby backgrounds, safer material handling, incremental architecture/performance improvements, and a verified fix for Issue #13. It also makes the Windows release QA deterministic across hosted-runner screen sizes. Existing training, review, contest, template, sync, and bilingual features remain available.
