# CF Compass v3.13.0-alpha.1

这是一个用于公开验收的 Alpha 预发布版本，重点升级记忆大厅的高清与动态背景能力，并在不重写现有训练功能的前提下整理背景架构、降低大图资源开销。题库、复习、今日训练、赛事中心、赛事复盘、模板库、自动同步和中英文界面均继续保留。

## 功能优化

- 记忆大厅新增“智能填充、全屏裁切、完整显示”三种画面模式。智能模式会根据素材和窗口宽高比，自动选择无黑边裁切或柔化延展。
- 支持最高 160 MB 的 PNG、JPG、WebP 高清静态背景，以及最高 2 GB 的 MP4、WebM 动态背景。
- 动态背景支持 `0.5×–1.5×` 播放速度；窗口失焦、最小化、页面隐藏或开启“减少动态效果”后会自动暂停。
- 自定义图片导入后保留高清原图，同时生成最长边 1280px 的轻量预览；原图负责清晰前景，预览图负责虚化背景。
- 旧本地素材库会在图片第一次显示时按需生成预览，以后直接复用缓存，不会在启动时批量处理所有素材。
- 素材库会在统一入口排除已知的不完整拆包图层，以及清单中声明为 `layer`、`sprite`、`thumbnail` 或 `transition` 的非壁纸资源；旧配置若选中了这些资源，会自动回退到可用大厅并提示隔离数量。

## Issue 修复

- 修复 [#13](https://github.com/qeffg/cf-compass/issues/13)：首次更换 Handle 并同步后，多年份热力图会错误带动整个应用横向滚动，造成左侧导航被遮挡、右侧出现空白。
- 年份选择现在只调整热力图年份条自身的滚动位置，不再调用会影响外层页面的 `scrollIntoView`。
- 新增 2560×1600、2016–2026 共 11 个年份的专项回归：初次载入、切换最早年份和切回最新年份时，应用根节点均保持 `scrollX = 0`。

## 架构优化

- 将图片/视频渲染、智能宽高比判断和动态暂停控制收拢到独立 `WallpaperStage` 组件。
- 将单图导入、格式与容量校验、预览生成、元数据维护收拢到独立背景服务。
- 将本地素材清单解析、路径安全、预览缓存和文件协议解析收拢到独立素材库服务。
- 将素材适用性规则拆成独立质量策略，第三方素材包可通过 `wallpaperReady: false` 或 `assetRole` 显式声明资源用途，避免在界面层堆积特例。
- 背景格式、容量和元数据边界集中配置，后续增加新格式时不再需要同时修改多个页面。
- 新增背景引擎、性能和 Issue #13 布局专项自动化验收。

## 性能优化

- 静态背景不再通过 Base64 塞入 IPC；高清原图与轻量预览分离，减少传输体积和重复高清解码。
- 素材清单按文件大小与修改时间缓存，未变化时直接复用解析结果。
- 首屏优先恢复题库、收藏和学习数据，背景与数据中心信息在首屏完成后利用空闲时间加载。
- 最近活动针对正常的倒序提交跳过重复排序，遇到外部导入的乱序数据仍自动回退到完整排序。
- 复用数字格式化器，题库缓存使用紧凑 JSON，背景缩略图使用延迟解码。

本机验收中，10 万条倒序提交的最近活动处理约提升至原实现的 `1.5×`；新旧打包版本 7 轮交错冷启动中位数相差约 `0.33%`，处于环境波动范围。性能结果会受电脑、杀毒软件和数据规模影响，因此这些数字只作为回归参考，不代表所有设备的固定提升。

## 验收范围

- Vite 正式构建、题意格式、Carrot 表现分、训练分析、年度热力图、性能与素材路径安全回归。
- 中文/English 界面及首次启动语言选择。
- 高清原图与预览分离、三种画面模式、沉浸大厅覆盖、WebM 真解码、循环、变速和节能暂停。
- 已知坏源、显式非壁纸角色和旧配置回退的素材隔离专项验收；隔离测试使用独立用户目录，不读取或修改真实数据。
- 打包后 Windows 程序的题库、赛事、复习操作和 Issue #13 多年份布局。
- Release 工作流会在原生 Windows 环境重新下载已发布程序、核对 SHA-256、完成真实启动和布局回归后，才自动回复并关闭本版本解决的 Issue。

## English summary

CF Compass v3.13.0-alpha.1 is a public preview focused on high-resolution and video lobby backgrounds, safer asset handling, and incremental architecture/performance improvements. It adds smart fill, cover, and contain modes; MP4/WebM playback controls and energy-aware pausing; original/preview image separation; on-demand preview caching; dedicated background services; and a material-quality policy that quarantines known incomplete layers or assets explicitly declared as non-wallpaper resources.

This preview also fixes Issue #13, where the multi-year activity selector could horizontally scroll the entire application after the first Handle sync and hide the navigation rail. A dedicated 2560×1600 regression now verifies that the root viewport remains anchored while switching across eleven years. Existing training, review, contest, template, sync, and bilingual features remain available.
