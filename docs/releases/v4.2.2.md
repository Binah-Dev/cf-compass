# CF Compass v4.2.2

发布准备中。仅在本次全部构建、安装与启动验收通过后正式发布；最终验证记录尚待补充。

## Linux AppImage 与更新工具支持

- AppImage 改用静态 type-2 runtime 和 zstd SquashFS，不再依赖系统 `libfuse2`。正常挂载启动仍需要可用的 FUSE 设备、辅助工具及兼容的 Linux 桌面环境。
- AppImage 文件名改为 `CF-Compass-4.2.2-x86_64.AppImage`，去掉多余的 `Linux` 段。Debian 包保持 `CF-Compass-4.2.2-Linux-amd64.deb`，旧版发布资产与链接不重命名。
- 稳定版 AppImage 嵌入标准更新信息，并附匹配的 `CF-Compass-4.2.2-x86_64.AppImage.zsync`，供外部 AppImageUpdate 等工具使用。CF Compass 内部不新增自动检查、下载或安装更新。
- 补充 AppStream 元数据和固定提交地址的演示工作台截图，供软件目录识别产品信息。截图说明产品界面，不替代 Linux 启动验证，也不代表目录页面已经更新。

## 首次使用与已有功能

首次启动直接进入内置演示工作台，无需登录或联网。演示账号和统计来源有明确标识，可先体验题目搜索、收藏与页面导航，再同步自己的 Codeforces 账号。已保存的语言选择继续沿用。

v4.2.1 的正式赛 / 虚拟赛综合估计 Rating、训练偏好、赛事复盘、笔记与目标题单继续保留。估计仍只供训练参考，官方数据不被覆盖；完整规则见 [v4.2.1 说明](./v4.2.1.md)。

## Ubuntu 24.04 与沙箱

Ubuntu / Debian 用户优先选择 `.deb` 安装包，通过系统包管理器安装和升级。

对限制用户命名空间的 Ubuntu 24.04，AppImage 需要一次性管理员许可：安装到管理员拥有的固定路径 `/opt/cf-compass/CF-Compass.AppImage`，再为该精确路径加载 AppArmor 配置。按 [Linux 安装与沙箱说明](../linux-appimage.md) 操作；应用运行时仍使用普通用户身份。应用不会自动添加关闭 Chromium 沙箱的参数，也不要求全局关闭系统的用户命名空间限制。

这不是 Ubuntu 24.04 开箱即用或所有 Linux 发行版兼容的承诺。已有 4.2.1 测试包在受限制的 Ubuntu 24.04 环境中启动失败；4.2.2 必须对文档中的安装方式重新验证后才能正式发布。最终适用环境以本版本验收记录为准。

## 从旧版升级

v4.2.1 AppImage 未嵌入更新信息，因此需要先从 GitHub Release **手动下载一次 v4.2.2**。此后，外部 AppImageUpdate 等工具才可依据新包中的元数据查找后续稳定版本。

后续跨版本更新需要未来稳定版本及其匹配 `.zsync` 实际发布。当前的元数据校验和完整本地种子重构只能验证打包链路，不能证明一次尚未发生的公开跨版本升级。`.zsync` 是更新工具使用的数据，不是安装包，也无需手动运行。

使用 Ubuntu 24.04 固定路径安装方式时，先在用户可写目录更新副本，再由管理员安装到固定路径；不要以 root 身份运行更新工具的图形界面。`.deb` 用户下载新版包后通过系统包管理器覆盖升级。已有用户数据和本地素材配置继续沿用；建议先从数据中心导出重要数据。

## 下载与完整性验证

目标附件为六个平台安装包及一个 AppImage 更新 sidecar：

| 平台 | 文件 |
| --- | --- |
| Windows x64 安装版 | `CF-Compass-4.2.2-Windows-x64-Setup.exe` |
| Windows x64 便携版 | `CF-Compass-4.2.2-Windows-x64-portable.exe` |
| Linux x64 AppImage | `CF-Compass-4.2.2-x86_64.AppImage` |
| AppImage 更新数据 | `CF-Compass-4.2.2-x86_64.AppImage.zsync` |
| Linux Debian x64 | `CF-Compass-4.2.2-Linux-amd64.deb` |
| macOS Intel | `CF-Compass-4.2.2-macOS-x64.dmg` |
| macOS Apple Silicon | `CF-Compass-4.2.2-macOS-arm64.dmg` |

不发布任何 `.sha256` 或 `SHA256SUMS.txt` 附件。CI 内部保留摘要校验和重新下载验证；需要自行核对下载时，可比较本机 SHA-256 与 GitHub Release 资产显示的摘要。Windows 包未购买商业代码签名证书；macOS 包使用 ad-hoc 签名，未经 Apple 公证。

## English summary

- Uses a static type-2 AppImage runtime with zstd SquashFS and the filename `CF-Compass-4.2.2-x86_64.AppImage`; the Debian filename retains `Linux`.
- Adds standard update metadata and a matching `.AppImage.zsync` for external tools such as AppImageUpdate. There is no in-app automatic updater.
- Keeps the offline demo workbench explicit about its identity and data sources, and adds AppStream metadata with an immutable screenshot URL.
- Users of the v4.2.1 AppImage must manually download v4.2.2 once. A real cross-version update requires a future stable release and has not yet been established by metadata or local reconstruction checks.
- Ubuntu / Debian users should prefer `.deb`. Restricted Ubuntu 24.04 AppImage use requires a one-time administrator-approved installation at `/opt/cf-compass/CF-Compass.AppImage` with an exact-path AppArmor profile. Run the app as an ordinary user; update a copy in a writable directory before administrator installation. Do not run updater GUIs as root.
- Preserves the Chromium sandbox and does not disable user-namespace restrictions globally. This is not a claim of universal Linux compatibility or unconfigured Ubuntu 24.04 support.
- Publishes no `.sha256` or `SHA256SUMS.txt` attachments; package verification remains internal to CI. Publication awaits all checks for this version; final validation evidence is still pending.
