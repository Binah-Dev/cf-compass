这是 CF Compass 3.13 的第三个公开 Alpha，完整继承高清/动态记忆大厅、素材质量隔离、背景架构与性能优化，并修复 Issue #13 的同步后整页横向偏移。

## 主要更新

- 记忆大厅支持智能填充、全屏裁切、完整显示，以及最高 160 MB 静态图和最高 2 GB MP4/WebM 动态背景。
- 高清原图与轻量预览分离；动态背景支持变速、失焦暂停与减少动态效果。
- 素材服务会隔离已知不完整图层，以及声明为非壁纸角色或 `wallpaperReady: false` 的条目。
- 背景渲染、导入、素材库和质量策略拆为独立模块；最近活动、素材索引和首屏加载路径完成增量性能优化。
- Issue #13 的年份选择只滚动热力图内部年份条，根页面不再横移，左侧导航不会被裁掉。

## 发布验收

- 源码验证与 Windows、Linux、macOS Intel、macOS Apple Silicon 原生构建必须全部成功。
- Windows 解包版必须通过素材隔离、主功能以及 2560×1600、2016–2026 多年份布局回归。
- 发布后的 Windows portable 必须从 GitHub Release 重新下载、匹配 SHA-256，并真实启动出 CF Compass 窗口。
- 只有上述检查全部通过，工作流才会回复并关闭本版本声明解决的 Issue。

## 下载

- Windows x64：`CF-Compass-3.13.0-alpha.3-Windows-x64-portable.exe`
- Linux x64：`CF-Compass-3.13.0-alpha.3-Linux-x86_64.AppImage`
- Debian / Ubuntu x64：`CF-Compass-3.13.0-alpha.3-Linux-amd64.deb`
- macOS Intel：`CF-Compass-3.13.0-alpha.3-macOS-x64.dmg`
- macOS Apple Silicon：`CF-Compass-3.13.0-alpha.3-macOS-arm64.dmg`

每个程序包均附独立 `.sha256`，并提供完整 `SHA256SUMS.txt`。Windows 尚未使用商业代码签名；macOS 使用可验证的 ad-hoc 签名但未经过 Apple Developer ID 公证。第三方图片、人物素材和用户本地数据不会进入源码或安装包。
