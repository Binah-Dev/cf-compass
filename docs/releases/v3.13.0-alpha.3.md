这是 CF Compass 3.13 当前唯一保留的公开 Alpha。它完整继承题库工作台、今日训练、间隔复习、赛事中心、赛事复盘、本地模板库、Codeforces 自动同步和中英文界面，并集中升级记忆大厅、素材管理、页面稳定性与发布验收流程。

本版本适合希望提前体验 3.13 新功能、愿意反馈问题的用户。日常使用需要更稳定版本时，仍建议选择最新正式版。

## 完整训练工作流

- 题库工作台支持题目状态、算法标签、Rating 区间、收藏状态与通过次数筛选。
- 今日训练按照当前 Rating、薄弱算法、历史练习和复习计划生成分层题单。
- 复习库保留刷题记录、间隔复习计划与可视化时间轴，方便回看已经完成的题目。
- 赛事中心可以检索并筛选 Codeforces 场次；赛事复盘集中展示表现分、实际排名、Rating 变化、赛时通过情况和赛后补题状态。
- 本地模板库按算法体系整理源码，支持搜索、题意摘要与直接在 VS Code 中打开。
- Codeforces 数据可以手动或自动同步；简体中文与 English 界面均继续保留。

## 高清与动态记忆大厅

- 支持 PNG、JPG、WebP 静态图片，以及 MP4、WebM 动态背景。
- 单张静态图片最高支持 160 MB，单个动态背景最高支持 2 GB。
- 提供智能填充、全屏裁切与完整显示三种布局，兼顾无黑边、主体完整和不同屏幕比例。
- 高清原图与最长边 1280px 的轻量预览分离：浏览素材时优先使用预览，进入大厅时再加载原始资源，减少无意义的大图解码。
- 动态背景支持 `0.5×–1.5×` 播放速度；窗口失焦、最小化、页面隐藏或开启“减少动态效果”后会自动暂停。
- 素材质量策略会隔离已知不完整图层，以及声明为 `layer`、`sprite`、`thumbnail`、`transition` 或 `wallpaperReady: false` 的非壁纸资源；失效选择会安全回退。
- 第三方图片、人物素材和用户本地数据不会进入源码、安装包或云端同步。

## 架构与性能优化

- 背景渲染、素材导入、素材库读取和质量判断已拆分为独立模块，后续扩展格式与导入方式不需要同时改动多个页面。
- 素材索引按照文件大小与修改时间复用缓存，旧素材的轻量预览按需生成，避免每次启动重新扫描和处理全部高清文件。
- 首屏优先恢复训练数据；背景、排名等次要信息延后加载，降低启动阶段的资源争抢。
- 最近活动在 Codeforces 返回正常倒序数据时跳过重复排序，减少大提交记录用户的同步开销。
- 页面仍保留完整现有功能，没有用删减题库、复习或赛事能力来换取表面上的启动速度。

## 页面偏移修复

- 修复 [Issue #13](https://github.com/qeffg/cf-compass/issues/13)：首次更换 Handle 并同步后，多年份热力图不再推动整个应用横向滚动。
- 年份切换只调整热力图内部年份条，不再滚动根页面；左侧导航不会被裁掉，右侧也不会出现大片空白。
- 已覆盖 2560×1600 窗口和 2016–2026 共 11 年数据的初始、最早年份与最新年份状态。

## 签名与 Alpha 说明

- Windows 构建尚未购买商业代码签名证书，因此 SmartScreen 可能显示“未知发布者”；请只从本仓库 Release 下载并核对 SHA-256。
- macOS 应用使用可验证的 ad-hoc 签名，但没有 Apple Developer ID 签名或公证；部分系统仍可能要求在“隐私与安全性”中确认打开。
- 这是公开测试版本。虽然已通过自动化与真实启动验收，但仍可能存在正式版发布前需要修正的边缘问题，欢迎通过 GitHub Issues 提供可复现步骤、系统版本和截图。

## English summary

CF Compass v3.13.0-alpha.3 is the current public Alpha for the 3.13 line. It preserves the complete problemset, daily training, spaced review, contest search and review, local template library, Codeforces synchronization, and bilingual interface while adding high-resolution image and MP4/WebM lobby backgrounds, safer local asset handling, incremental startup and indexing improvements, and the verified Issue #13 viewport fix.

All Windows, Linux, macOS Intel, and macOS Apple Silicon packages include checksum files. The published Windows portable package was downloaded again from GitHub, verified against `SHA256SUMS.txt`, and cold-started with isolated user data before this release was accepted.
