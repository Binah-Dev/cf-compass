# CF Compass v3.12.1

这是针对 macOS 分发可靠性的补丁版本，重点修复 [Issue #12](https://github.com/qeffg/cf-compass/issues/12) 中 Apple Silicon 用户遇到的“应用已损坏，无法打开”问题。

## 修复内容

- macOS Intel 与 Apple Silicon 应用现在使用明确的 **ad-hoc 签名**，不再发布完全无签名的 `.app`。
- Intel 包在原生 Intel runner 构建，Apple Silicon 包在原生 arm64 runner 构建，并分别执行实际启动存活测试。
- GitHub Actions 会在制作 DMG 后执行严格的深度签名验证；主应用或任一内部组件签名不完整，整个 Release 都会停止。
- 关闭无 Developer ID 场景下不适用的 Hardened Runtime，避免 Electron arm64 应用因签名与运行时配置冲突而无法启动。
- Release 发布后会重新下载全部平台程序包并核对 `SHA256SUMS.txt`；只有校验全部通过才回复并关闭 Issue。
- 更新中英文安装说明，明确区分真正的文件损坏与 macOS 对未公证应用的 Gatekeeper 拦截。

## 重要说明

ad-hoc 签名可以保证应用包及内部组件具有一致、可验证的签名，但它不等同于 Apple Developer ID 签名或 Apple 公证。项目目前没有付费 Apple Developer 证书，因此从浏览器下载后，macOS 仍可能要求用户在“隐私与安全性”中确认来源。

如果系统仍显示“已损坏”，请先核对下载文件的 SHA-256，确认来自本仓库 Release，然后将应用复制到 `/Applications` 并运行：

```bash
xattr -dr com.apple.quarantine "/Applications/CF Compass.app"
```

## 下载

- Windows x64：`CF-Compass-3.12.1-Windows-x64-portable.exe`
- Linux x64：`CF-Compass-3.12.1-Linux-x86_64.AppImage`
- Debian / Ubuntu x64：`CF-Compass-3.12.1-Linux-amd64.deb`
- macOS Intel：`CF-Compass-3.12.1-macOS-x64.dmg`
- macOS Apple Silicon：`CF-Compass-3.12.1-macOS-arm64.dmg`

每个程序包均附带独立 `.sha256`，同时提供完整的 `SHA256SUMS.txt`。

## English summary

This patch fixes the macOS distribution problem reported in Issue #12. Intel and Apple Silicon apps are now built and smoke-tested on native runners, ad-hoc signed, and rejected by CI unless `codesign --deep --strict` succeeds. After publication, every platform package is downloaded again and verified against `SHA256SUMS.txt` before the issue is closed. The project does not yet have a paid Apple Developer ID, so the app is not notarized and Gatekeeper approval may still be required after checksum verification.
