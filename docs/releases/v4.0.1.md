# CF Compass v4.0.1

这是一次针对 Windows 启动体验的维护版本。应用功能与 v4.0.0 保持一致，重点是为普通用户增加启动更稳定的标准安装版。

## Windows 下载建议

| 文件 | 适合谁 | 启动方式 |
| --- | --- | --- |
| `CF-Compass-4.0.1-Windows-x64-Setup.exe` | **推荐绝大多数 Windows 用户下载** | 安装时解压一次，之后直接从安装目录启动 |
| `CF-Compass-4.0.1-Windows-x64-portable.exe` | 临时使用、U 盘携带或不希望安装的用户 | 每次启动都要释放程序文件，通常会更慢 |

便携版不是程序卡死：它在显示启动画面时仍可能正在解压，并可能被 Windows Defender 或第三方杀毒软件逐项扫描。设备磁盘较慢时，这个过程会更加明显。长期使用请优先选择安装版。

安装版提供安装目录选择、桌面快捷方式、开始菜单入口与卸载程序。卸载默认不会删除 CF Compass 的题库、设置、模板、笔记和本地素材；重新安装或覆盖升级后仍可继续使用原数据。

> 当前 Windows 公共构建没有商业代码签名证书，因此安装版和便携版都可能显示 SmartScreen“未知发布者”。请只从本仓库 Release 下载，并先核对 SHA-256。

## 其他系统

Linux AppImage、Linux deb、macOS Intel 与 macOS Apple 芯片版本的打包方式均未改变。v4.0.1 Release 原样附带 v4.0.0 已验证文件，不修改内容、不重命名版本：

- `CF-Compass-4.0.0-Linux-x86_64.AppImage`
- `CF-Compass-4.0.0-Linux-amd64.deb`
- `CF-Compass-4.0.0-macOS-x64.dmg`
- `CF-Compass-4.0.0-macOS-arm64.dmg`

## 发布验证

- Windows 安装版会在隔离目录完成静默安装、首次启动、再次启动与卸载验证。
- 安装版和便携版都会在发布后重新下载并核对 `SHA256SUMS.txt`。
- 便携版继续执行真实冷启动验证，确保启动画面之后能够出现 CF Compass 主窗口。
- Linux 与 macOS 文件直接从正式 v4.0.0 Release 下载并重新纳入 v4.0.1 的完整 SHA-256 清单，避免无功能变化的重复构建。
