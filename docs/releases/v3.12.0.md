# CF Compass v3.12.0

这次更新把 CF Compass 从单一平台训练工具推进为完整的跨平台、双语训练工作台。

## 主要更新

- **简体中文 / English 一键切换**：主要页面、弹窗、动态计数、系统对话框和无障碍提示均已适配；题目名称、模板内容和用户数据保留原文。
- **个人训练数据中心**：支持生涯、近一年、三个月、一个月、两周及自定义时间范围，集中查看 Rating 变化、算法通过率、AC 数量与训练节奏。
- **Codeforces Rating 图表升级**：采用清晰的段位背景、节点数据和底部时间轴，并支持鼠标滚轮缩放。
- **年度刷题热力图重做**：按 `0 / 1 / 2 / 3+` 次 AC 显示颜色强度，支持左右切换年份和悬停查看当日过题数。
- **题库隐私训练选项**：可以隐藏题目的算法标签，同时保留 Rating，减少标签对独立思考的干扰。
- **算法表现排行**：按通过率展示算法分类，并可滚动查看所选时间范围内的完整统计。
- **本地人物与背景素材支持**：应用可以读取用户自行准备的本地素材库；第三方图片不会进入源码、安装包或云端同步。使用方法见[可选素材指南](https://github.com/qeffg/cf-compass/blob/v3.12.0/docs/OPTIONAL_CHARACTER_ASSETS.md)。
- **三平台正式发布**：回应 [Issue #10](https://github.com/qeffg/cf-compass/issues/10)，新增 Linux 与 macOS 构建，并保留 Windows 免安装版本。

## 下载校验与首次启动

每个程序包旁均提供同名 `.sha256` 文件，同时提供完整的 [`SHA256SUMS.txt`](https://github.com/qeffg/cf-compass/releases/download/v3.12.0/SHA256SUMS.txt)。本次发布的五个程序包已经过实际下载与 SHA-256 复核。

当前公开构建没有商业代码签名证书，因此 Windows SmartScreen 可能显示“未知发布者”，macOS 首次打开时也可能要求在“隐私与安全性”中确认来源。请只从本仓库 Release 下载，并在运行前核对 SHA-256。

## English summary

CF Compass v3.12.0 adds a complete Simplified Chinese / English interface, a customizable training analytics center, a zoomable Codeforces Rating chart, an improved yearly AC heatmap, optional problem-tag hiding, and scrollable algorithm acceptance rankings.

This release also introduces verified packages for **Windows x64, Linux x64, macOS Intel, and macOS Apple Silicon**. Every package includes an individual SHA-256 file plus a complete checksum manifest. Optional character and background assets remain local-only and are not bundled with the public source or downloads.

For the complete project guide, see the [English README](https://github.com/qeffg/cf-compass/blob/v3.12.0/README.en.md).
