# CF Compass v4.2.1

## 正式参赛 + 虚拟参赛，统一估计 Rating

- 个人评分显示简化为「真实模式」和「综合估计模式」。旧版虚拟专用模式设置会迁移到综合估计模式，不沿用旧的虚拟专用评分结果。
- 综合估计将正式参赛与虚拟参赛按参加时间排入同一条评分记录，使用上一场的估计 Rating 继续计算，而不是简单叠加官方涨跌分。
- 对支持的近期普通比赛，即使官方 Rating changes 尚未公布，也可利用最终榜单和参赛者公开 Rating 快照进行临时估算；不依赖比赛题目先获得难度评级。
- 启用综合估计时，后台发现比赛记录并在已知虚拟赛结束后自动尝试计算，完成后更新界面和今日训练，无需反复手动刷新。
- 官方评级公布后会替换对应临时依据并重算评分链，避免同一场重复计分。暂缺依据或部分参赛者缺失时会显示状态并重试。

## 推荐与体验

- 今日训练支持使用综合估计分；自动模式跟随个人评分显示选择，手动指定的训练参考分始终优先。
- 修复无历史评级时的估计异常，增加账号切换、缓存、失败重试及旧设置迁移回归。
- 统一正式与虚拟参赛的赛事复盘布局，并恢复 README 功能图集。

## 使用方式与边界

在个人评分切换器选择综合估计模式，或在今日训练偏好中选择综合估计参考分。默认仍保留真实模式；官方 Rating 和原始个人数据不会被估计结果覆盖。

这是**训练参考估计，不是官方 Rating 预测承诺**。未结算比赛的快照估计目前限定为最近 7 天内、榜单已结束且未冻结的受支持普通 Codeforces / Educational / Global Round；特殊赛制、缺失成绩或尚未结束的比赛可能需要等待。参赛资格、赛前历史 Rating、新用户规则及公开榜单覆盖不足都会影响精度。界面会提示临时估计和缺失依据。

“赛后自动”表示在应用运行、相关模式启用且 API 数据可用时自动尝试；实际更新时间受 Codeforces 数据公布、网络和限流影响，不保证瞬时完成。无需 AI API 或付费服务。

## 下载与数据

提供 Windows 安装版 / 便携版、Linux AppImage / deb、macOS Intel / Apple Silicon DMG。下载后可对照 `SHA256SUMS.txt` 校验。macOS 包采用临时签名，并非 Apple 公证版本。

升级保留用户数据与本地素材配置；安装包不包含测试账号数据或个人素材。重要本地数据仍建议在升级前备份。

## English summary

- Adds an opt-in combined rating ledger for chronological official and virtual participation, including provisional estimates for supported recent finished but unrated rounds.
- Automatically retries pending evidence, updates training recommendations after completion, and rebuilds the ledger when official rating evidence becomes available.
- Keeps official data unchanged and manual training ratings authoritative; migrates the retired virtual-only display mode.
- Unifies official/virtual contest replay presentation and restores the README gallery.
- Estimates are training references, not official-rating guarantees. Current-rating snapshots, incomplete fields, eligibility and newcomer rules may limit accuracy. API availability and rate limits affect update timing.
