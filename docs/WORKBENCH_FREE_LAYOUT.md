## 产品行为

- 对象是题库页的算法分类、题目列表、个人进度三个框，不是模板题意弹窗或主题选择抽屉。
- 旧实现仅用 HTML 拖放交换顺序，尺寸固定在 12 列网格中。新实现可以在工作台范围内自由移动和八方向拉伸，允许重叠。
- 顶部常显拖动条，右下角常显拉伸提示，操作时展示实时尺寸。方向键微调，Shift 加大步幅；拖动中按 Esc 或发生 pointercancel 时取消本次操作。
- 每个面板可展开至工作台大小，再还原到原来的位置和尺寸；顶部面板按钮能把被遮挡的面板置顶。
- 原“智能排列”改为“智能复位”，同时恢复三个框的位置和尺寸，退出展开状态并清除自由布局记录；不会重置题目、笔记、主题或个人数据。
- 默认宽屏三列，小屏采用左侧分类/进度上下排列、右侧题目列表；不会再在小屏直接隐藏个人进度。
- 题目列表按面板宽度调整搜索与 Rating 筛选布局，过窄时内容在面板内部滚动。面板有最小尺寸和工作台边界，不支持拖出应用成为独立系统窗口。

## 持久化与边界

- 使用独立 localStorage key `cf-compass-workbench-layout-v2`，位置和尺寸以画布比例保存；保留旧顺序 key，作为旧用户宽屏预设迁移依据。
- 只在松手或键盘操作结束时保存；窗口尺寸变化后按当前可用空间约束，重启恢复仍可见的几何布局。
- 非法版本、缺少字段、非数值、负值或越界存档回退到预设；存储失败时明确提示本窗口临时生效。
- 自由布局允许重叠，因此缩小窗口后不保证各框互不覆盖；置顶按钮、单框展开和智能复位都能帮助恢复可用视图。
