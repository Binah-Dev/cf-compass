## Findings and changes

1. **Saved enhanced review lost evidence.** The main-process sanitizer retained report prose but discarded source timeline and Diff arrays. A direct comparison against v4.1.1 reproduced `sourceDiffs: undefined`; the candidate preserves bounded, whitelisted display evidence. Renderer reopen tests cover saving, application restart, separate virtual sessions, and no provider calls.
2. **Old reports silently regenerated.** Missing evidence previously forced regeneration. Saved prose is now reused even for legacy records; explicit reanalysis is required to regenerate unavailable evidence. Saved reports remain viewable without source credentials.
3. **Premature saved state.** The review drawer now awaits the persistence result before marking the returned report saved. A failed save retains its unsaved state.
4. **Late requests crossed drawer/session boundaries.** Request generations discard stale review and recommendation results after close, reopen, another request, or unmount. Mock-provider UI tests deliver deliberately delayed responses to verify isolation.
5. **Recommendation target metadata could be absent.** Missing contest-problem ratings/tags are filled from the synced problemset by exact problem identity. Candidate weights and hard exclusions are unchanged. Identical complete metadata yields identical candidates. Unknown ratings/tags are not invented.
6. **Misleading empty-result message.** Missing library, missing target metadata, and no eligible matches now have separate Chinese/English explanations. Empty candidates never reach the provider. The drawer explains that the local problemset comes from Problemset > Sync Data, not the template library.
7. **Unknown time and Diff whitespace.** Null timestamps remain unknown rather than becoming zero; legitimate zero-second events survive. Diff context prefixes and trailing newlines are retained, and truncation is marked.
8. **Title bar fragmentation/customization.** A single opaque, full-width surface replaces stacked decoration and translucent backing. Default hue follows the theme; custom hex color is validated and persisted. Light backgrounds use dark text. Preview/cancel, theme reset, reload persistence, window controls, narrow widths, and immersive hiding are covered.
9. **English omissions.** Navigation accessibility text and the empty-template-library state now translate. Obsolete navigation/page selectors were corrected in the i18n audit; page existence checks no longer swallow timeouts.
10. **QA async-wait defect.** Five persistence waits used asynchronous predicates with synchronous truthiness polling. Save traces showed checks could read the previous value before the write completed. A bounded async-aware helper now polls the actual persisted state. It has regression coverage for retry and timeout.
11. **QA screenshot reliability.** Typography capture uses Electron's native compositor while retaining all readability/geometry assertions. Earlier dynamic-import and screenshot failures remain in evidence; builds must not be replaced under a running QA process.

## Remaining boundaries

- This is a bounded regression audit, not proof that every bug is gone.
- No real paid provider response was requested. Provider behavior and the reporter's exact local files remain unverified.
- Legacy source details already discarded by older saves cannot be recovered from prose; saved prose remains readable and reanalysis is explicit.
- New contests without published metadata, or a genuinely exhausted candidate pool, may legitimately yield no recommendation.
- macOS/Linux native packaging and published-download checks must run before a future release. No new version is published by this change.
- Windows display scaling may round CSS focus offsets to fractional pixels; tests allow at most half a CSS pixel while requiring an inset focus ring.
