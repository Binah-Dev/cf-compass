# 可选人物与背景素材指南

CF Compass 不在仓库或 Windows 程序中重新分发第三方角色素材，但允许你把合法取得的图片或视频导入自己的本地副本。这样既能保留个性化视觉，也能让代码仓库、安装包与素材版权保持清晰边界。

> 本页提供来源导航和使用说明，不授予任何第三方素材的版权。下载、修改、展示或传播前，请以原始页面的最新许可为准。

## 可访问的原始来源

### 1. Shittim Canvas NEXT

- 项目官网：[Shittim Canvas NEXT](https://sc.japerz.com/)
- 用途：从项目官方渠道了解软件、资源包、版本说明与素材安装方式。
- 注意：网站展示的 GPL-3.0 主要是软件代码许可，不应自动理解为《Blue Archive》角色、美术、语音和游戏提取资源也采用 GPL。下载前请阅读该站的 Privacy & Copyright Policy；不要把提取资源重新提交到 CF Compass 仓库。

### 2. Blue Archive 官方数字周边

- 官方入口：[Blue Archive Digital Merch Shop](https://forum.nexon.com/bluearchive-en/board_view?board=3218&thread=2121367)
- 用途：寻找官方明确提供下载的壁纸、头像和其他数字周边。
- 官方页面列出的条件包括注明原始创作者、仅作非营利用途，以及衍生作品采用相应 Creative Commons 许可。只有页面明确覆盖的数字周边适用这些条件，不能扩大解释为全部游戏资源。

### 3. Arona 与 Plana 插画

- 作品索引：[Arona And Plana Blue Archive — HDQWalls](https://hdqwalls.com/wallpaper/2048x1152/arona-and-plana-blue-archive)
- 页面标注作者：[Rasutohda 的 Pixiv 主页](https://www.pixiv.net/en/users/14340444)
- 注意：作品索引和作者署名不等于开放转载许可。除非作者页面另有明确授权，建议只下载后本地使用，不要重新打包、镜像或声明为 MIT/CC 素材。

## 在 CF Compass 中使用

1. 从原作者或官方页面取得图片或视频文件。
2. 打开 CF Compass，点击左侧栏底部的调色盘图标进入 **外观设置**。
3. 在 **本地人物与背景** 中点击 **导入本地素材**。
4. 选择文件后，背景会立即预览；点击 **完成** 保存设置。
5. 如需更换，点击 **更换素材**；如需恢复纯 CSS 主题，点击 **移除素材**。

桌面版支持以下格式：

| 类型 | 格式 | 大小限制 |
| --- | --- | --- |
| 静态图片 | PNG、JPG/JPEG、WebP | 最大 160 MB |
| 动态背景 | MP4、WebM | 最大 2 GB |

浏览器开发模式仅支持 PNG、JPG/JPEG、WebP，单张最大 15 MB。

## 推荐制作规格

- 横屏素材优先使用 `16:9`，推荐 `1920 × 1080` 或 `2560 × 1440`。
- 静态图推荐导出为 WebP，在画质和体积之间更均衡。
- 人物尽量放在画面右侧或边缘，避免遮住中部题目列表。
- 角色拆分图层应先合成为一张完整、不透明的 16:9 场景图；不要把带有大片透明区、假黑底或零散部件的拆包图层直接当作大厅背景。
- 动态背景推荐 H.264 MP4 或 VP9 WebM，并控制码率，减少长时间运行时的资源占用。

## 文件保存在哪里

桌面版导入后会把素材复制到 Electron 的本机用户数据目录，并保存为 `custom-wallpaper` 文件；它不会写入 Git 仓库，也不会同步到 Codeforces。再次导入会替换上一份本地素材，点击 **移除素材** 会删除这份应用内副本。

## 贡献边界

欢迎改进导入功能、排版样式和本指南，但请不要在 Pull Request、Issue、演示截图或 Release 中上传来源不明的角色素材。若你希望贡献一份可随项目分发的原创素材，请同时提供作者、原始链接和明确的开源许可证。
